⭐ Featured project — DevPulse
<div align="center">🟣 DevPulse — SaaS Monitoring & Incident Management
Monitor applications, detect failures early, and manage incidents from one unified platform.

</div>
DevPulse is an observability and incident orchestration platform designed around practical engineering operations.
Capability	What it does
Multi-tenancy & RBAC	Organization-level isolation, JWT authentication, refresh tokens, and role-based permissions
Application monitoring	Configurable HTTP health checks, schedules, timeouts, and latency measurements
Incident lifecycle	Automatic incident creation and recovery based on consecutive check results
Alerting	Email and webhook notifications with cooldowns and delivery history
SLA analytics	Availability windows, uptime metrics, and latency trends
Real-time updates	Live status changes through WebSocket (STOMP over SockJS)
Administration	Platform-level statistics and security audit history
